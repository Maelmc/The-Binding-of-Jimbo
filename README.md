# The Binding of Jimbo
The Binding of Jimbo is a full content mod for Balatro, adding content based on The Binding of Isaac: Rebirth and its DLCs. On top of adding new things to already existing categories (Jokers, consumables, blinds, packs...), it adds the new Active and Trinket cards, which respectively act similar to reusable consumables and Jokers while having their own area! [Mod wiki](https://balatromods.miraheze.org/wiki/The_Binding_of_Jimbo)

The mod has its own [Discord server](https://discord.gg/T2sCN3x6WK)! Please report any bugs or issues there or [on the Issues page](https://github.com/Maelmc/The-Binding-of-Jimbo/issues) so I can hopefully fix them, and feel free to make suggestions. Please use the latest code before reporting issues, the releases may be out of date with the current code.

**Prerequisites**

Both [Lovely](https://github.com/ethangreen-dev/lovely-injector) (use latest release if you can, some things may be broken on earlier versions) and [Steamodded](https://github.com/Steamopollys/Steamodded) (use latest release) must be installed. Follow [this tutorial](https://github.com/Steamodded/smods/wiki/) to see how to install them if you haven't yet.

**Installation**

1. Download the zip file with the contents of the repository (Code -> Download Zip)
2. Create a folder named The Binding of Jimbo inside your mods folder
3. Extract the zip file into the mods folder. Make sure that there is a single folder between the mods folder and the contents. (i.e. it should go Mods\The Binding of Jimbo\contents and not Mods\The Binding of Jimbo\The Binding of Jimbo\contents or Mods\contents, where contents are the inner files)
4. Make sure the files are directly under the The Binding of Jimbo folder in your mods folder and not under the zip file folder
   (In other words, unzip the file and then copy and paste BindingOfJimbo.json, main.lua, the folders etc to be under the The Binding of Jimbo folder in the Mods folder)

**Sprites**

The mod currently uses placeholder art for most elements (Jokers, Actives, Trinkets, Loots, Spectral, enhancements, packs...). Guest artists are welcome! Want your art in the game? Join our [Discord](https://discord.gg/T2sCN3x6WK)! The eventual goal, even if that sounds like an herculean task considering the amount of stuff in Isaac, is to have proper art for every card in the mod.
